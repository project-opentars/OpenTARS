Before anything risky, it asks.

Every command is checked against a fixed list of dangerous patterns. These are plain rules, not AI, so nothing can talk them out of it. Nothing runs until you click Allow.

  • rm -r
  • dd
  • mkfs
  • curl | sh
  • git reset --hard
  • shutdown

New: openTARS Pi 1.1.

Your Raspberry Pi or Orange Pi, in plain words. It finds the file you mean, does tasks with several steps, drives the pins and answers in words. No cloud, no GPU, no account.

curl -fsSL https://github.com/project-opentars/OpenTARS-Pi/releases/latest/download/install.sh | bash

Then type opentars.

  • 1 GB of RAM is enough. Tested on an Orange Pi Zero 2W.
  • 30 of 40 everyday tasks it had never seen, up from 19 in 1.0.
  • 0.6 s for board status, files, memory and pins.
  • Your yes first. Only commands that just read run on their own.

New in 5.3 Tesseract

  • Rebuilt on llama.cpp. One fast engine for every model, installed for you. No separate AI program to set up.
  • Gargantua 2.5 on Gemma 4. The new main AI sees your screen and hears your voice.
  • Voice, understood directly. What you say goes straight to Gargantua 2.5, in English or Portuguese.
  • Missions in a virtual machine. On Linux, Gargantua Pro works inside a disposable computer. You watch it live and choose which files come back.
  • A model store with search. Search the Ollama library right from Settings and see what fits your machine.
  • A terminal that looks the part. A framed prompt, a status bar with the model, the engine and your folder, and formatted answers.
  • One-click updates everywhere. Windows, macOS and every Linux update from inside the app.
  • Clicks in Chromium and Electron apps. With your permission, openTARS reopens them with accessibility on, so it can click their buttons by name.
  • A smarter assistant. Calendar, notes, e-mail, music and system settings by sentence, all off until you turn them on.

Install it in a minute.

The installer sets up everything, downloads the models and tests them. Updating keeps your chats and settings.

Windows 10 or 11

irm https://raw.githubusercontent.com/project-opentars/OpenTARS/main/app/empacotamento/windows/instalar.ps1 | iex

In PowerShell. Everything goes into your user folder.

macOS 12 or newer

curl -fsSL https://raw.githubusercontent.com/project-opentars/OpenTARS/main/app/empacotamento/macos/instalar.sh | bash

In Terminal. The first run asks for Accessibility and Screen Recording.

wget -O /tmp/opentars.deb https://github.com/project-opentars/OpenTARS/releases/latest/download/opentars_all.deb && sudo apt install -y --reinstall /tmp/opentars.deb

What was tested

Ubuntu, Debian, Linux Mint, Zorin OS and Pop!_OS, on X11 and Wayland, with NVIDIA, AMD or the processor alone. Every change runs our automated tests on Linux, Windows and macOS, including the llama.cpp engine downloading and running a model. We have used openTARS on real Windows and Fedora computers. No real Mac has run it yet, so tell us what breaks.

Remove it, or go back to 5.2

To remove openTARS on any system, run opentars --desinstalar.

If 5.3 does not run on your computer, 5.2 Ranger is still available. It uses Ollama as its engine.
