Tell your Linux desktop what to do.

openTARS is an AI assistant that does the work on your computer. It opens programs, presses buttons by their name, types, runs commands and looks at the screen. With a local Ollama model, processing stays on your machine; cloud models and web search are optional.

Ask the way you would ask a person.

In English or Portuguese, typed, spoken or from the terminal. A few things people ask, and what openTARS does with them:

  1. Open the calculator and work out 7 + 2

    Opens Calculator and presses each key by the text on it, through Linux accessibility. It works in milliseconds, even on Wayland.

  2. Make a folder called Invoices in my Documents

    Knows where your personal folders are, in your language, and creates it.

  3. What is using all my memory?

    Runs the command, reads the output and answers in plain words.

  4. Delete the old logs in Downloads

    Stops first. It shows you the exact command with Allow and Deny, and nothing is removed until you choose.

  5. Every weekday at 8, open the news

    Saves a routine that runs while openTARS is open, and tells you if one was skipped.

How it stays safe.

An assistant that can run commands has to know when to stop and ask. openTARS has three checks, and none of them can be talked out of by the AI.

  1. Risky commands wait for you

    Before anything runs, every command is matched against a fixed list of dangerous patterns. These are plain rules, not AI, so they cannot be argued with. A match turns into a card with Allow and Deny, and nothing happens until you click.

    • rm -r
    • rm *
    • find -exec rm
    • curl | sh
    • sudo
    • ssh
    • dd
    • mkfs
    • git reset --hard
    • shutdown

  2. It checks its own work

    When a task has several steps, the AI has to compare what you asked with what it actually did before it says “done”. If something is missing, it goes back and finishes.

  3. Routines never decide alone

    A scheduled routine can only delete, send or install if you allowed that when you created it. Anything else makes it stop and tell you.

The cloud is off by default

Local models are the default. If you choose an Ollama Cloud model, your request is processed by Ollama. Optional web search sends the search text to the SearXNG service you configure. Your Ollama sign-in stays with Ollama, and the window warns when a cloud model is selected.

Three models, one crew.

Each one has a single job. The installer downloads them through Ollama, and you can still add any other Ollama model next to them.

Thinks

Gargantua

The main AI. A Qwen3 4B model trained on thousands of real openTARS requests, each one checked, so it already knows every tool it can use: opening apps, clicking, typing, running commands.

Size
about 2.5 GB
Runs on
a graphics card with ~3 GB free, or the CPU with 8 GB of RAM

Sees

Cooper

A vision model for questions about screenshots and controls that Linux accessibility cannot identify. It is cooper:1.2, about 636 MB (607 MiB), and the installer and the first-run window download it. An older, larger Cooper that is already installed keeps working.

Size
about 636 MB (607 MiB), optional
Needs
a graphical session

Routes

Murph

A tiny classifier in plain Python. It reads each request in about 0.2 ms and decides what kind it is (an action, a search, something on screen, code) so the right model answers.

Size
about 4 MB
Runs on
the CPU, in RAM. It never touches the graphics card

Two smaller Gargantuas you can add with one command. Same tools, same safety rules, a quarter of the size. We tested both on requests they never saw during training.

Writes code

Gargantua Code

Trained to write a script, run it, fix what fails and explain what a file does, using the same openTARS tools. When it is installed, openTARS sends coding requests to it first. It explains code less well than it writes it.

Test

Runs anywhere

Gargantua Lite

The everyday Gargantua in a much smaller model that also sees images, for computers without a graphics card and with little memory. It opens apps, handles files, searches and answers questions, and it runs fine on the processor alone. It makes more mistakes than the full model, most of all when it has to look at a picture. Computers without a graphics card and with little memory get it on their own; anywhere else, pick it in the model picker.

Install it in a minute.

One package installs everything openTARS needs: system packages, Ollama, its own Python environment and the models. If you can copy and paste, you can install it.

Download opentars_all.deb
Version
5.1 Tesseract
Size
1.1 MB
Updated
October 17, 2026
SHA-256
320a6faa5fb8af05a81f79f664d34209ee63539877e3863b0c3ca4d9ce2b710f

Open the file with your software center, or run sudo apt install ./opentars_all.deb in the folder where it was saved. To check the download first: sha256sum opentars_all.deb must print the SHA-256 above.

Or paste one line in a terminal

wget -O /tmp/opentars.deb https://github.com/project-opentars/openTars-lightweight-local-addon/raw/main/opentars_all.deb && sudo apt install -y --reinstall /tmp/opentars.deb

Then open openTARS from your app menu. The first run checks Ollama, downloads Gargantua with a progress bar you can pause, and tests it with a quick sum. Updating later keeps your chats and settings.

Tested on

  • Ubuntu
  • Debian
  • Linux Mint
  • Zorin OS
  • Pop!_OS

Any distro with apt should work. X11 and Wayland, NVIDIA, AMD or CPU only.

Need the older 4.6 Endurance?

4.6 is the release before the new window: the simpler Tk window, Ollama only, without voice or attachments. Use it only if 5.1 does not run on your computer.

It does not get the security fixes from 5.0 and it will not tell you when a new version comes out. Commands like rm with wildcards and curl | sh are not confirmed the way 5.0 does it.

Download 4.6 Endurance (.deb, 0.7 MB) 
wget -O /tmp/opentars-4.6.deb https://github.com/project-opentars/openTars-lightweight-local-addon/raw/5a9ea9f/opentars_all.deb && sudo apt install -y --allow-downgrades /tmp/opentars-4.6.deb

To go back to the current version, run the install command above again.

New in 5.1

Out now. Update from the app, or download the .deb above.

  • Three modes: Lite, Base and Pro

    Chosen on first run and switchable any time in Settings. Lite is just the chat, the microphone and attachments. Pro adds advanced settings and diagnostics. Updating keeps everything you had.

  • Probes

    Small watchers for a folder, a web page, news and releases (RSS, YouTube, GitHub), this computer (battery, temperature, internet, updates), a program or a git project. Three steps to create one, no AI needed, or write a mission in your own words. Alerts come with a bell next to the clock and inside the app. They only read; off until you turn them on. Moving a file is up to you; sending something to the trash asks every time.

  • Gargantua Lite, built in

    Computers without a graphics card and with little memory get the smaller Gargantua from the first run: 0.6 GB, and it sees images.

  • Gargantua Code

    An optional coding model handles programming requests when installed.

  • A terminal like today's AI tools

    Resume a conversation, compact it, see how much context is left, plan before acting, review a diff before any file changes and undo it, read an AGENTS.md, and use opentars -p in scripts.

  • Cloud with your Ollama account

    Sign in without copying keys. Still off by default, and a cloud model is only used when you pick it.

  • Web search through SearXNG

    Off by default. The AI can search and read pages through a SearXNG on your own computer, and pages are treated as data, never as instructions.

  • More reliable tool use and fallback

    Fixes help Gargantua use its tools more reliably, and automatic fallback no longer switches to a much smaller model mid-request.
