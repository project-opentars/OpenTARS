Before anything risky, it asks.

Every command is checked against a fixed list of dangerous patterns. These are plain rules, not AI, so nothing can talk them out of it. Nothing runs until you click Allow.

  • rm -r
  • dd
  • mkfs
  • curl | sh
  • git reset --hard
  • shutdown

Install it in a minute.

The installer sets up everything, downloads the models and tests them. Updating keeps your chats and settings.

Windows 10 or 11

irm https://raw.githubusercontent.com/project-opentars/OpenTARS/main/app/empacotamento/windows/instalar.ps1 | iex

In PowerShell. Everything goes into your user folder.

macOS 12 or newer

curl -fsSL https://raw.githubusercontent.com/project-opentars/OpenTARS/main/app/empacotamento/macos/instalar.sh | bash

In Terminal. The first run asks for Accessibility and Screen Recording.

Ubuntu, Debian, Mint, Zorin, Pop!_OS

wget -O /tmp/opentars.deb https://github.com/project-opentars/OpenTARS/releases/latest/download/opentars_all.deb && sudo apt install -y --reinstall /tmp/opentars.deb

What was tested

Ubuntu, Debian, Linux Mint, Zorin OS and Pop!_OS, on X11 and Wayland, with NVIDIA, AMD or the processor alone. Windows, macOS, Fedora, Arch and openSUSE are new in 5.2: they pass our automated tests, and we have also used them on real Windows and Fedora computers. No real Mac has run openTARS yet, so tell us what breaks.

Remove it, or use the older 4.6

To remove openTARS on any system, run opentars --desinstalar.

If 5.2 does not run on your computer, 4.6 Endurance is the last version with the simpler window. It does not have the security fixes from 5.0 and will not tell you about new versions.
