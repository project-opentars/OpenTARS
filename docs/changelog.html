Changelog

What changed in each version of openTARS. Updates install from the same package: your chats and settings are kept.

5.1 Tesseract

October 16, 2026

  • Three modes: Lite (chat, microphone, attachments), Base (adds history, memory, routines, Probes and the cloud) and Pro (adds advanced settings and diagnostics). Chosen on first run, switchable in Settings; updating from 5.0 keeps you in Pro.
  • Probes: a mission in your own words becomes a plan you check; the Probe only reads and tells you with a notification. The system tray shows when the background service is on, and new alerts also appear inside the app. Off by default; keys, passwords and browser data are off limits. Optional actions you choose: move what it finds to a folder, or send it to the trash after you approve each time.
  • Gargantua Lite on computers without a graphics card and with little memory, from the first run and the installer.
  • Terminal: opentars -p for scripts (with JSON output), resume, compact, context, plan and auto modes, file edits with a diff and your approval, undo, AGENTS.md, /init and !command.
  • Cloud with your Ollama account, no key to copy. The footer now also warns when the chosen model is an Ollama cloud model.
  • Web search through SearXNG, off by default.
  • When a model fails mid-request, the automatic switch never drops to a much smaller model.

5.0 Tesseract

October 6 to 15, 2026

October 15 update: two small Gargantuas are now available as optional downloads, Gargantua Code and Gargantua Lite (see the models section on the home page).

October 15 update: Gargantua now uses its tools much more reliably. openTARS was asking Ollama to turn reasoning off in a way that made Gargantua think it should answer right away, so sometimes it replied without doing the task. In our tests Gargantua used its tools in 18 of 18 tries, up from 15.

October 13 update: closing openTARS now unloads only the models it loaded itself (and Cooper), instead of every model in Ollama, so other programs that share Ollama keep theirs. The “unload all models” command still unloads everything. Also removed a voice help line that mentioned options that do not exist.

October 11 update: the mascot is now called KIPP, after the third robot of Interstellar, and its tips were rewritten. The Update button now really installs the new package (before, it could say it had updated without changing anything), checks the result, and looks for updates every 6 hours while the window is open.

A new window built in Qt, on top of the lean 4.6 core: Ollama underneath, Cooper looking at the screen and Gargantua as the official AI.

  • First run in five steps: language, Ollama, optional cloud, downloading Gargantua with a progress bar you can pause, and a quick test.
  • History by day with search, a model picker, a Stop button and the steps of each task with their timings.
  • Risky commands turn into a card with Allow and Deny.
  • Voice is back, fully local: hold to talk, continuous, or the wake word “TARS”.
  • Attachments, a visible memory you can edit, and scheduled routines that never decide alone.
  • An optional cloud with your own account, off by default and never used by the automatic model choice.
  • Updates noticed by the app itself, verified against GitHub and installed after you confirm.
  • A quick bar on Ctrl+Alt+Space.
  • A code audit with about 50 fixes: atomic settings files, more commands that ask first (rm with wildcards, find -exec rm, curl | sh, ssh), and the cloud key never passed to commands.

Updated on October 10

  • A mascot that walks along the chat, shows what the AI is doing and naps after a few quiet minutes.
  • A terminal styled like today's AI command-line tools: welcome panel, steps you can follow, a spinner and a clearer /help.
  • Fixes: opentars --voz, turning the update check fully off, commands ending in &, and more mv commands that ask first.

4.6 Endurance

October 4 and 5, 2026

The lighter release: it only removed what was heavy or unused.

  • Ollama only: external servers and importing .gguf files from other programs were removed.
  • Only Cooper looks at the screen: OCR, the zoom grid and the fallback vision model were removed.
  • Less dead code and fewer duplicated command-line options.
  • Voice, attachments and routines were removed here and came back in 5.0.

Still available for download at the end of the install section.

4.5 Endurance

October 3 and 4, 2026

  • Cooper, a vision model fine-tuned to find buttons, read fields and list windows on a screenshot.
  • WSL 1 and 2, with the Ollama running on Windows found automatically.
  • A terminal mode for servers and SSH sessions without a screen.
  • From 28 to 19 tools, and more than 40 fixes, including Stop while a model loads and a real right click.

4.0 Endurance

September 30 to October 2, 2026

  • Gargantua, the official AI: a Qwen3 4B trained to use openTARS, downloaded by the installer.
  • Murph, a tiny classifier that decides the type of each request in about 0.2 ms.
  • Longer tasks, the real names of your personal folders, and a notice when a new version comes out.
